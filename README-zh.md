# 牛了个牛

[English](README.md)

一个在浏览器里打开就能玩的叠牌三消。每一关都有解。难度只由花色数量决定，同一个链接永远是同一关。

直接玩：https://yixin-zhu.github.io/My-Match-3-game/

## 怎么玩

牌桌一共十二层、180 张牌。上面没有牌压住时，这张牌才能拿。奇数层错开半张牌，压在下层几张牌的接缝上。把压住接缝的牌拿走，下面的牌就会露出来。

拿起来的牌进入下面的 7 格卡槽。三张相同的花色会消掉，不必挨在一起。第七格放进去仍凑不成三张，这一关就输了。牌桌清空则赢。

- **花色**决定难度，从 2 到 35。花色越少越好过。2 到 3 种时，只要一直拿能拿的牌，最后一定会清空。从 4 种开始，拿错就可能把卡槽塞满，但这关仍然有一条能过的拿法。
- **种子**决定是哪一关。地址里会带上这两项，例如 `#s=7&t=8`。把这个地址发给别人，打开的就是同一关。
- **开这一关**按当前花色和种子开局，也可以重开这一关。
- **随机一关**换一个新种子。
- **撤销**收回上一步。电脑上也可以按 `Ctrl+Z`。

## 本地运行

需要 Node.js 20 或更新版本。

```bash
npm install
npm run dev
```

然后打开 http://localhost:5173/

| 命令 | 作用 |
| --- | --- |
| `npm test` | 检查规则，并确认生成的关卡确实能通关 |
| `npm run build` | 做类型检查，并把静态网页写到 `dist/` |
| `npm run preview` | 在本地打开构建好的网页 |

推送到 `main` 分支后，会自动跑测试，并用 GitHub Pages 发布。

## 代码在哪

| 文件 | 做什么 |
| --- | --- |
| `src/layout.ts` | 十二层牌桌。上层牌压在下层的接缝上 |
| `src/rules.ts` | 能不能拿、卡槽、三消、胜负 |
| `src/generator.ts` | 按种子和花色数量生成一关有解的牌 |
| `src/view.ts` | 画出牌桌和卡槽 |
| `src/main.ts` | 按钮、撤销，以及地址里的种子 |
| `src/icons.ts` | 牌面上的图案 |

游戏里不会把答案显示出来。发牌时先排好一条合法的拿牌顺序，再沿这条顺序分配花色，发出去之前还会自己把这条顺序走一遍。沿这条顺序会撑满卡槽的牌局不会被使用。
